# 니케 모작 유즈케이스

## 작성 현황

7개 기능 영역에 총 38개 유즈케이스가 작성되어 있습니다. 현재 문서는 요구사항 초안이며, API 계약과 구현 완료를 의미하지 않습니다. 모든 개발 담당자는 아직 미정입니다.

## 전체 흐름

플레이어는 계정으로 로그인한 뒤 니케를 모집하고 육성하여 스쿼드를 편성하며, 전투에서 획득한 보상과 소셜 활동으로 다시 모집과 성장 과정을 반복한다.

## 문서 구성

| 기능 영역 | 개요 | 문서 |
|---|---|---|
| 계정 | 계정 생성과 인증 및 프로필을 관리한다. | [계정 유즈케이스](Account.md) |
| 소셜 | 플레이어 검색과 친구 관계 및 친구 포인트를 관리한다. | [소셜 유즈케이스](Social.md) |
| 니케 관리 | 보유 니케의 성장과 스킨 및 장비를 관리한다. | [니케 관리 유즈케이스](NikkeManagement.md) |
| 니케 모집 | 모집 정보를 확인하고 재화를 사용하여 니케를 획득한다. | [니케 모집 유즈케이스](Recruitment.md) |
| 스쿼드 관리 | 전투에 사용할 니케 편성을 조회하고 변경한다. | [스쿼드 관리 유즈케이스](Squad.md) |
| 전투 | 스테이지 입장부터 전투 수행과 결과 및 보상 처리까지 관리한다. | [전투 유즈케이스](Battle.md) |
| 인벤토리 | 보유 아이템의 정보와 사용 결과를 관리한다. | [인벤토리 유즈케이스](Inventory.md) |
| 합계 | 7개 영역, 38개 유즈케이스 |  |

## 기능 연계

`계정 → 니케 모집 → 니케 관리 → 스쿼드 관리 → 전투 → 보상 획득 → 인벤토리 → 니케 관리`

소셜에서 획득한 친구 포인트는 소셜 포인트 모집에 사용되며, 모집으로 획득한 니케는 니케 관리와 스쿼드 관리 및 전투로 이어진다.
